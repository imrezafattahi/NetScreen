NetScreen installation

Free network monitoring with FastAPI, SQLite and a vanilla JavaScript dashboard.

Docker

git clone https://github.com/imrezafattahi/NetScreen.git
cd NetScreen
docker compose up -d

Local

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --app-dir backend --reload

URLs

Dashboard · API docs · Health

Monitoring

Add ping, HTTP, HTTPS or DNS targets. Results are stored in SQLite. Ping uses ICMP where supported and a labelled TCP fallback otherwise. HTTPS checks include basic certificate connectivity and HTTP status monitoring.
